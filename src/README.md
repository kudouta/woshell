# src — woshellメイン

プロンプト `-> ` に C の式に似た 1 行を打つと、その場で計算したり、プログラムの中の関数を名前で呼んだりできるshellです。画面は `vtermlib/` の端末が描くので、エスケープシーケンスで文字の飾りや倍幅の行なども使えます。build方法は、woshell の `README.md`にあります。

特に意味はありませんが名前の「wo」は、日本語の「魚（うお）」から来ています。

```
-> x = 3 + 4 * 2
new variable "x"
value = 11 = 0xb
-> printf "\e[1mbold\e[m \e[7mreverse\e[m x=%d", x
bold reverse x=11
value = 31 = 0x1f
-> d 0x80000, 16, 1
00080000:  00 7c 07 00 23 cf 00 08 f4 70 4f f9 00 0a 1e 50  *.|..#....pO....P*
value = 0 = 0x0
-> beep 880, 300
value = 0 = 0x0
```

（`bold` は太字、`reverse` は白黒反転で表示されます。`printf` の値は出した文字の数で、エスケープシーケンスの文字も数えます。`d` で見えるのはプログラムの先頭で、中身はビルドごとに変わります）

**状態**: 実験的なものです。シリアルと `ramscan` を除くほとんどの機能は、MAME と実機の両方で確認しました（「確認したこと」を参照）。

## ファイル

| ファイル | 内容 |
|---|---|
| `main.c` | 起動の処理 |
| `shell.c` | 行の編集、式の解析と実行 |
| `cmds.c` | 組み込みの関数（`cmd_…`） |
| `console.c` | 端末とシリアルに出す |
| `symtab.h` | シンボルテーブルの形（テーブルそのものはビルドのときに作る） |

## できること

- C の式（演算子の優先順位は C と同じ）、シェルの変数、文字列
- プログラムの関数と変数を名前で呼ぶ・読む・書く（リンクのときに作るシンボルテーブルを使う）
- メモリの表示と書き換え、割り込みの回数、時計（RTC）と PRAM、シリアル
- 呼んだ関数がバスエラーなどを起こしたときや、本体の割り込みボタンを押したときは、プロンプトに戻ります。
- 画面は 85 桁 x 28 行（6 x 12 ドットの文字）です。VT102 と xterm の一部のエスケープシーケンスが使えます（`vtermlib/README.md`）。
- 画面に出すものは、エスケープシーケンスも含めてシリアルにも出します。PC の端末からも同じように使えます。
- 起動すると、本体の ROM から起動のアイコン（ROM がフロッピーから起動するときに画面の中央に出す 32 x 32 の絵）を読み、起動したときに出す文の左に出します。SE/30 の ROM でだけ出て、絵はこのリポジトリーには入っていません（`hal/README.md` の「ROM の起動のアイコン」）。文字が流れると一緒に流れて消えます。

## 書き方

1 行が 1 つの文です。

| 書き方 | 意味 | 例 |
|---|---|---|
| 式 | 計算して結果を出す（`value = 10進 = 16進`、印字できる値なら `= '文字'` も） | `3 + 4 * 2`、`0x1000 >> 4`、`'A'` |
| 名前 = 式 | 変数に入れる。なければシェルの変数を作る。プログラムの変数ならそのメモリに書く | `x = 5` |
| 関数 引数, ... | 関数を呼ぶ（かっこなしでよい） | `d 0x80000, 64` |
| 関数(引数, ...) | 式の中でも呼べる | `x = ticks() + 60` |

- 数: 10 進、`0x` で始まると 16 進、`0` で始まると 8 進、`'A'` は文字のコード
- 文字列 `"..."` の値は、その文字列を置いたアドレスになります（文字列はシェルの中の 8KB の領域に置き、古いものから上書きされます）。`\n` `\t` `\a`（ベル） `\e`（ESC） `\x41` などが使えます。
- 名前: シェルの変数 → プログラムのシンボルテーブル の順に探します。関数の名前はそのアドレス、変数の名前はその中身（32 ビット）です。`&名前` でアドレス、`*式` でそのアドレスの 32 ビットを読み書きします。
- 演算子: C と同じ優先順位の `* / % + - << >> < <= > >= == != & ^ | && || =` と、単項の `- ~ ! * & +`
- 関数の引数は 10 個まで、すべて 32 ビットの整数として渡します。

### 組み込みの関数（`help` で一覧）

C では `cmd_` で始まる関数です（`cmd_help`、`cmd_d`）。シンボルテーブルには `cmd_` を外した名前でも入るので、`help`、`d` のように打てます（`cmd_help` と打っても同じです）。

| 関数 | 内容 |
|---|---|
| `help` | 一覧 |
| `d [addr[,n[,width]]]` | メモリを表示（n 個、幅 1/2/4。省略すると前の続き） |
| `m addr[,width]` | メモリを書き換え（16 進で入力。Enter で次、`.` で終わり） |
| `printf "fmt", ...` | 書式付き出力（`%d %x %s %c %u %o %p`、幅、`-`、`0`） |
| `h` / `vars` | 入力の履歴 / シェルの変数 |
| `mem` | メモリの配置 |
| `malloc n` / `free p` | メモリを取る（`free` は何もしない） |
| `ticks` / `delay n` | 垂直同期の回数 / n 回の垂直同期を待つ |
| `irqs` | 割り込みのレベルごとの回数と、処理する関数がなかった割り込みの回数と要因 |
| `date` | 時計の日時を表示 |
| `setdate 年,月,日[,時,分,秒]` | 時計を合わせる（1904〜2039 年） |
| `pram [addr[,n]]` / `pramw addr, v` | PRAM（256 バイト）を表示 / 1 バイト書き換える |
| `cls` / `version` / `reboot` | 画面を消す / 版 / ROM から起動し直す |
| `serial` | 使っているシリアルポートと速さ、送受信のバイト数・誤りの数 |
| `port 'a'` / `port 'b'` | モデムポート / プリンターポートに切り替える |
| `baud n` | シリアルの速さを変える（300〜57600 のうち 115200 を割り切るもの、115200、230400） |
| `serout 0` / `serout 1` | 画面に出すものをシリアルにも出すのをやめる / 出す |
| `scrbench [lines]` | 画面の読み書きの時間と、文字を流す速さを測る |
| `beep [hz[,ms]]` | 音を鳴らす（省略すると 880Hz、120ms） |
| `wo` | 魚 `<o))))><` が今の行を右から左へ泳いでいく（垂直同期 2 回で 1 桁進む。実機なら約 3 秒） |
| `mmu [addr]` | MMU とキャッシュの状態と、変換テーブルのあらまし。アドレスを渡すと、そのアドレスの変換（`hal/README.md` の「MMU とキャッシュ」） |
| `ramscan [start[,end]]` | 物理 RAM がどこにあるかを 1MB ごとに調べる（省略すると、ROM が見つけた RAM の次から調べる。書いた値はすぐ戻す。`hal/README.md` の「RAM の量」。実機では 16MB より上を調べると止まる） |

プログラムの中の関数（`beep`、`vt_puts`、`memset` など）も同じように名前で呼べます。

`setdate` と `pramw` は本体の時計と設定を書き換えます。実機の PRAM を書き換えると Mac OS の設定が変わるので、`pramw` は使い道の決まっていない場所で試してください。

### キー

| キー | 動作 |
|---|---|
| ← → / Control-B, F | カーソルを動かす |
| Home, End / Control-A, E | 行の先頭 / 終わりへ |
| Delete / Del、Control-D | 前 / 後ろの文字を消す |
| Control-U / Control-K | 行を消す / カーソルから後ろを消す |
| ↑ ↓ / Control-P, N | 履歴（16 行） |
| Control-C | 入力をやめる |
| Control-L | 画面を消す |

キーは押し続けると 0.5 秒後から 1 秒に 20 回繰り返します（ADB のキーボードは自分では繰り返さないので、ソフトで作っています）。

## しくみ

```
keyboard -> VTermLib -> shell.c     キーを ESC [ A などのバイト列にして渡す
serial   -------------> shell.c     シリアルから来たバイト列もそのまま渡す
                        shell.c     行の編集、式の解析と実行
shell.c  -> console.c -> VTermLib   エスケープシーケンスを解釈して画面に描く
                      -> serial     同じバイト列をシリアルにも送る
```

割り込み、割り込みボタン、シリアル、時計のくわしいしくみは `hal/README.md` にあります。

## シリアル

起動したときはモデムポート、9600bps、8 ビット、パリティなし、ストップビット 1 です。

- 画面に出すものはすべてシリアルにも出します（改行は CR LF。エスケープシーケンスもそのまま送るので、PC の端末にも同じ飾りが出ます）。
- 端末から打った文字は、キーボードと同じように受け取ります。Enter（CR、CR LF、LF のどれでも）、後退（0x7F / 0x08）、矢印・Home・End・Delete（エスケープシーケンス）が使えます。
- 速さは `baud` で変えます（選べる速さは上の表。115200 と 230400 は MAME では試せません）。
- つなぎ方（mini-DIN8 と RS-232 の変換器の配線）と、しくみは `hal/README.md` にあります。MAME でのつなぎ方は woshell の `README.md` の「動かすときの補足」にあります。

## 確認したこと

- PC: 端末（VTermLib）の中身のテスト（`make test`。項目は `vtermlib/README.md` の「確認したこと」）
- MAME: 起動、ROM の起動のアイコン、`help`、式と変数、`printf` でのエスケープシーケンス（太字、反転、下線、倍幅の行、線画文字）、`beep` の呼び出し、`serial`（送ったバイト数が増える）、`date`、`d`、`mmu`、`ramscan`（RAM 2MB・8MB・32MB）、バスエラーからプロンプトへの戻り、`wo`、端末デモ
- 実機（2026-11-20）: 起動、ROM の起動のアイコン、`help`、式と変数、エラーの表示、`printf` でのエスケープシーケンス（太字、反転、下線、倍幅の行）、`wo`、`beep`、`d`、`irqs`、`mmu`、`date`、`setdate`、`pram`、`pramw`、`serial`（送信だけ）、`scrbench`、アドレスエラーからプロンプトへの戻り、キーボード（編集、履歴、繰り返し、Shift、Caps Lock）、割り込みボタン、`reboot`。くわしい結果は woshell の `README.md` の「実機で確認した項目」にあります
- このシェルの元になった、公開していない版（画面を VTermLib ではなく自前で描いていた版）で確認したこと: MAME でのシリアル（9600bps、両方のポート）
- まだ確認していないこと: この版のシリアルの送受信、実機のシリアル、115200 / 230400bps、実機でのバスエラーからの戻り
- 実機でうまく動かないこと: `ramscan`（16MB より上を調べると止まります）
