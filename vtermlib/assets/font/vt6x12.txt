; VTermLib の文字 (6 x 12 ドット = 12 ポイント相当)。2026-11-18 に新しく描いたもの
;
; 書き方
;   size W H        1 文字のます目の幅と高さ (ドット)。幅は 1-8。画面の桁数と行数はここから決まる
;                   (SE/30 の 512 x 342 なら、6 x 12 で 85 桁 x 28 行)
;   underline N     下線を引く行 (0 から数える)
;   [c]             次の H 行が文字 c (ASCII 0x20-0x7E) の形
;   {c}             次の H 行が、DEC の線画文字 (ESC ( 0 で選ぶ文字の組) で c (0x5F-0x7E) に当たる形
;   形の 1 行は '#' (点灯) と '.' (消灯) を W 個
;   ';' で始まる行と空行は読み飛ばす。書いてない文字は空白 (線画文字は ASCII の形) になる
;
; この文字の決まり
;   英数字は左から 1-5 列目 (幅 5) に描き、6 列目は文字の間のすきま (太字はここへ 1 ドット太らせる)
;   大文字と数字は 3-10 行目、小文字の x の高さは 5-10 行目、g j p q y の下がる部分は 11-12 行目
;   線画文字はます目いっぱいに描き、縦線は 3 列目、横線は 7 行目を通る (隣の文字とつながる)
;
; 書き換えたら make し直せば反映される (tools/common/vtfont.py が build/font.h にする)。
; 別のフォントを使うときは  make FONT=assets/font/ほかのファイル.txt
